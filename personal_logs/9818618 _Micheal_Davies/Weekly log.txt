### US-28 — Compare Scenario Score to Current Score

* Added a `ScenarioComparison` model holding the current score, the scenario score, the difference, and the direction of change.
* Added `compareToCurrent` to `ScenarioService` so both scores are produced by the same calculation.
* Updated the Scenarios screen to show both scores together with the difference.
* Worded and coloured the difference as better, worse, or no change so the direction is unambiguous.

### Score Integration

* Identified that no score calculation existed yet, as `PlaceholderScoreService` is still an empty stand-in for Epic 6.
* Added a `ScoreCalculator` abstraction and an `IndicativeScoreCalculator` implementation so US-28 could be completed.
* The calculator scores each of the four domains per person against a rough benchmark and averages them into a score out of 100.
* The benchmark figures are placeholders and the scores are labelled as indicative only in the UI.
* This still needs to be raised with the owners of US-20 and US-21 so the Epic 6 scoring can replace it through the same interface.

### US-29 — Save a Scenario

* Added a `SavedScenario` model and a `ScenarioDao` abstraction with a `SqliteScenarioDao` implementation.
* Saved scenarios are stored in the existing `scenarios` table, so no schema change was required.
* Added a scenario name field and Save Scenario button to the Scenarios screen.
* Scenarios are saved against the household so they are visible to all household members.
* Added validation so a scenario without a name is rejected and guests cannot save.

### US-30 — View Saved Scenarios

* Added a Saved scenarios list to the Scenarios screen showing each scenario's name and scores.
* Added an Open action that reloads the saved values and the scores they had when saved.

### US-31 — Delete a Saved Scenario

* Added a Delete action for each saved scenario with a confirmation dialog.
* Deleting removes the scenario permanently and only if it belongs to the current household.
* Household resource data is not affected by deleting a scenario.
